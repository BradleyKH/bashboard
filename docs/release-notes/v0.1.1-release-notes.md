## New

- **Find in file previews.** Text previews in the Files pane have a Find button and bar (Ctrl+Shift+F in the pane) that works like the terminal's find: case insensitive, Enter and Shift+Enter step through matches, and Esc closes the bar and selects the current match. It works in code, rendered markdown, and the text editor.
- **Move panes between tabs from the dashboard.** Drag a pane's title strip or card onto another tab's group in the Panes section to move it there without switching tabs. An expanded pane splits the target tab's focused pane, or lands collapsed (with a toast) when there's no room. A tab left empty by the move closes.
- **Open in File Explorer from the Files pane.** The breadcrumb has the same folder button as the dashboard rows, opening the current folder in File Explorer.

## Changes

- The backdrop starts on a still frame by default. Turn on the backdrop's Animate setting to bring the colony to life.
- New backdrop defaults: 20 fps, speed 10, capacity 1000, mutation rate 0.2, zoom 2. The scrim and its medium preset default to 0.5 opacity.
- While Animate is off, the settings dialog hides the backdrop fields that have no effect on a still frame.
- A favorite whose label is still its folder's name shows the parent folder under the label, so the name doesn't appear twice. Renamed favorites keep the full path, and the tooltip always shows it.
